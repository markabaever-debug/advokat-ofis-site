Адвокат-офис

Русский · English

«Адвокат-офис» — личная программа адвоката Маркабаева Е. Б. для ведения дел. Это программа для Windows, она работает на компьютере владельца и не предназначена для других пользователей.

Политика конфиденциальности

Хранение данных

Все данные программы хранятся только локально на компьютере владельца. Программа не имеет собственного сервера и не передаёт данные о делах на сторонние серверы.

Доступ к Google Календарю

Программа запрашивает доступ к Google Календарю владельца (calendar.events — события; calendar.calendarlist.readonly — только просмотр списка календарей, чтобы выбрать календарь для записи). Этот доступ используется только для того, чтобы создавать, изменять и удалять события программы (судебные заседания и другие процессуальные события) в календаре владельца, выбранном в настройках, и сверять их с уже существующими событиями. Другие календари и события, не созданные программой, программа не изменяет.

Ключ доступа Google хранится только на компьютере владельца в зашифрованном виде.

Передача данных

Данные не передаются третьим лицам, не продаются и не используются для рекламы. Данные, полученные через API Google, используются в соответствии с Правилами использования пользовательских данных Google API, включая требования об ограниченном использовании (Limited Use).

Отзыв доступа

Отозвать доступ программы к Google-аккаунту можно в любой момент на странице myaccount.google.com/permissions.

Advokat-ofis

“Advokat-ofis” (Lawyer’s Office) is a personal case-management application of attorney Ye. B. Markabayev. It is a Windows application that runs on the owner’s computer and is not intended for other users.

Privacy Policy

Data storage

All application data is stored only locally on the owner’s computer. The application has no server of its own and does not send case data to third-party servers.

Google Calendar access

The application requests access to the owner’s Google Calendar (calendar.events — events; calendar.calendarlist.readonly — read-only list of calendars, used to choose the target calendar). This access is used only to create, update and delete the application’s own events (court hearings and other procedural events) in the owner’s calendar selected in the settings, and to check them against existing events. The application does not modify other calendars or events it did not create.

The Google access token is stored only on the owner’s computer, encrypted.

Data sharing

Data is not shared with third parties, not sold and not used for advertising. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke the application’s access to your Google Account at any time at myaccount.google.com/permissions.
